# Day-2: Remove Duplicate Elements from an Array

## Problem Statement

Write a C program to remove duplicate elements from an integer array.

## Input

- Number of elements
- Array elements

## Output

- Display the array after removing duplicate elements.

## Example

### Input

8
10 20 10 30 20 40 30 50

### Output

10 20 30 40 50

## Concept Used

- Arrays
- Nested loops
- Comparison
- Element shifting

## Time Complexity

O(n²)

## Space Complexity

O(1)
