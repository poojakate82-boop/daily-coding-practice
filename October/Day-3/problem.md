# Day-3: Find the Second Largest Element

## Problem Statement

Write a C program to find the second largest distinct
element in an integer array.

## Input

- Number of elements
- Array elements

## Output

- Display the second largest distinct element.

## Example

### Input

6
10 45 23 78 56 78

### Output

Second largest element = 56

## Concept Used

- Arrays
- For loop
- Conditional statements
- Variable initialization
- Comparison

## Time Complexity

O(n)

## Space Complexity

O(n)
