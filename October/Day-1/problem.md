# Day-1: Find Largest and Smallest Element

## Problem Statement

Write a C program to find the largest and smallest elements in an integer array.

## Input

- Enter the number of elements.
- Enter the array elements.

## Output

- Display the largest element.
- Display the smallest element.

## Example

### Input

6
25 10 45 78 12 30

### Output

Largest element = 78
Smallest element = 10

## Constraints

- 1 <= n <= 100
- Array elements are integers.

## Concept Used

- Arrays
- For loop
- If statement
- Comparison
- Variable initialization

## Time Complexity

O(n)

## Space Complexity

O(n)
