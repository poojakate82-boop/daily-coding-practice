# Day-4: Count Frequency of Each Element

## Problem Statement

Write a C program to count and display the frequency
of each element in an integer array.

## Input

- Number of elements
- Array elements

## Output

- Display each element and its frequency.

## Example

### Input

8
10 20 10 30 20 10 30 40

### Output

10 -> 3
20 -> 2
30 -> 2
40 -> 1

## Concept Used

- Arrays
- Nested loops
- Conditional statements
- Frequency counting

## Time Complexity

O(n²)

## Space Complexity

O(n)
