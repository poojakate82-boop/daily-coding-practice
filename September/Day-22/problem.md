# Day-22: Selection Sort

## Problem Statement

Write a C program to sort an array in ascending order using the Selection Sort algorithm.

## Input

- Enter the number of elements.
- Enter the array elements.

## Output

- Display the sorted array.

## Example

### Input

5
64 25 12 22 11

### Output

11 12 22 25 64

## Constraints

- 1 <= n <= 100

## Concept Used

- Arrays
- Selection Sort
- Nested Loops
- Swapping
