# Day-23: Insertion Sort

## Problem Statement

Write a C program to sort an array in ascending order using the Insertion Sort algorithm.

## Input

- Enter the number of elements.
- Enter the array elements.

## Output

- Display the sorted array.

## Example

### Input

5
12 11 13 5 6

### Output

5 6 11 12 13

## Constraints

- 1 <= n <= 100

## Concept Used

- Arrays
- Insertion Sort
- Loops
- Element Shifting
