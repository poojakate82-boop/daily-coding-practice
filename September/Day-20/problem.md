# Day-20: Count Vowels, Consonants, Digits, and Spaces

## Problem Statement

Write a C program to count the number of vowels, consonants, digits, and spaces present in a string.

## Input

- Enter a string.

## Output

- Display the number of vowels.
- Display the number of consonants.
- Display the number of digits.
- Display the number of spaces.

## Example

### Input

Hello World 123

### Output

Vowels = 3
Consonants = 7
Digits = 3
Spaces = 2

## Constraints

- String length <= 100 characters

## Concept Used

- Strings
- Character Arrays
- Loops
- Conditional Statements
- Character Classification
