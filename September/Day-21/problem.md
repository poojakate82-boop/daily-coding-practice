# Day-21: Binary Search

## Problem Statement

Write a C program to search for an element in a sorted array using the Binary Search algorithm.

## Input

- Enter the number of elements.
- Enter the sorted array elements.
- Enter the element to search.

## Output

- Display the position of the element if found.
- Otherwise display "Element not found".

## Example

### Input

5
10 20 30 40 50
30

### Output

Element found at position 3

## Constraints

- 1 <= n <= 100
- Array must be sorted in ascending order.

## Concept Used

- Arrays
- Binary Search
- Loops
- Conditional Statements
