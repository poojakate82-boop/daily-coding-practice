# Day-7: Find the Smallest Element

## Problem Statement

Write a C program to accept `n` integers in an array and find the smallest element in the array.

## Input

- Enter the number of elements `n`.
- Enter `n` integer elements.

## Output

- Display the smallest element in the array.

## Example

### Input

5
25 10 45 5 30

### Output

Smallest element = 5

## Constraints

- `1 <= n <= 100`
- Array elements are integers.

## Concept Used

- Arrays
- For loop
- If statement
- Array indexing
