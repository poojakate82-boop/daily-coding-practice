# Day-17: Find Length of a String Without Using strlen()

## Problem Statement

Write a C program to find the length of a string without using the built-in strlen() function.

## Input

- Enter a string.

## Output

- Display the length of the string.

## Example

### Input

Hello World

### Output

Length of string = 11

## Constraints

- String length <= 100 characters

## Concept Used

- Strings
- Character Arrays
- While Loop
- String Traversal
