# Day-6: Sum of Array Elements

## Problem Statement

Write a C program to accept `n` integers in an array and calculate the sum of all elements.

## Input

- Enter the number of elements `n`.
- Enter `n` integer elements.

## Output

- Display the sum of all array elements.

## Example

### Input

5
10 20 30 40 50

### Output

Sum of array elements = 150

## Constraints

- `1 <= n <= 100`
- Array elements are integers.

## Concept Used

- Arrays
- For loop
- Variables
- Arithmetic addition
