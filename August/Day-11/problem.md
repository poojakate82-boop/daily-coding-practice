# Day-11: Sort Array in Ascending Order

## Problem Statement

Write a C program to accept `n` integers in an array and sort them in ascending order using the Bubble Sort algorithm.

## Input

- Enter the number of elements `n`.
- Enter `n` integer elements.

## Output

- Display the sorted array in ascending order.

## Example

### Input

5
45 12 78 23 10

### Output

10 12 23 45 78

## Constraints

- 1 <= n <= 100
- Array elements are integers.

## Concept Used

- Arrays
- Nested loops
- Bubble Sort
- Swapping
