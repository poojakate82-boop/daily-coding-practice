# Day-14: Merge Two Arrays

## Problem Statement

Write a C program to accept two arrays and merge them into a single array.

## Input

- Enter the size of the first array.
- Enter the elements of the first array.
- Enter the size of the second array.
- Enter the elements of the second array.

## Output

- Display the merged array.

## Example

### Input

First Array:
10 20 30

Second Array:
40 50 60

### Output

Merged Array:
10 20 30 40 50 60

## Constraints

- 1 <= size <= 100
- Array elements are integers.

## Concept Used

- Arrays
- Loops
- Array Merging
- Indexing
