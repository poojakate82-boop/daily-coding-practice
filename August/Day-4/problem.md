# Day-4: Reverse an Array

## Problem Statement

Write a C program to accept `n` integers in an array and print the elements in reverse order.

## Input

- Enter the number of elements `n`.
- Enter `n` integer elements.

## Output

- Display the array elements in reverse order.

## Example

### Input

5
10 20 30 40 50

### Output

50 40 30 20 10

## Constraints

- `1 <= n <= 100`
- Array elements are integers.

## Concept Used

- Arrays
- For loop
- Array indexing
