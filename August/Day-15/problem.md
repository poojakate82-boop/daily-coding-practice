# Day-15: Matrix Addition

## Problem Statement

Write a C program to add two matrices of the same size and display the resultant matrix.

## Input

- Enter the number of rows and columns.
- Enter the elements of the first matrix.
- Enter the elements of the second matrix.

## Output

- Display the resultant matrix after addition.

## Example

### Input

Rows = 2, Columns = 2

First Matrix:
1 2
3 4

Second Matrix:
5 6
7 8

### Output

6 8
10 12

## Constraints

- 1 <= rows, columns <= 10
- Matrix elements are integers.

## Concept Used

- 2D Arrays
- Nested Loops
- Matrix Operations
- Matrix Addition
