# Day-3: Count Even and Odd Numbers

## Problem Statement

Write a C program to accept `n` integers in an array and count the number of even and odd elements.

## Input

- The first line contains the number of elements `n`.
- The next line contains `n` integer elements.

## Output

- Display the total number of even elements.
- Display the total number of odd elements.

## Example

### Input
6
10 15 22 7 8 13

### Output
Even numbers = 3
Odd numbers = 3

## Constraints

- `1 <= n <= 100`
- The array contains integer values.

## Concept Used

- Arrays
- For loop
- If-else
- Modulus (`%`) operator
