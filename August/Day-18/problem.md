# Day-18: Reverse a String Without Using strrev()

## Problem Statement

Write a C program to reverse a string without using the built-in strrev() function.

## Input

- Enter a string.

## Output

- Display the reversed string.

## Example

### Input

Hello

### Output

olleH

## Constraints

- String length <= 100 characters

## Concept Used

- Strings
- Character Arrays
- Loops
- String Traversal
