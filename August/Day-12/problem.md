# Day-12: Sort Array in Descending Order

## Problem Statement

Write a C program to accept `n` integers in an array and sort them in descending order using the Bubble Sort algorithm.

## Input

- Enter the number of elements `n`.
- Enter `n` integer elements.

## Output

- Display the sorted array in descending order.

## Example

### Input

5
45 12 78 23 10

### Output

78 45 23 12 10

## Constraints

- 1 <= n <= 100
- Array elements are integers.

## Concept Used

- Arrays
- Nested loops
- Bubble Sort
- Swapping
