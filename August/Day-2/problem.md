# Day-2: Find the Second Largest Element

## Problem Statement

Write a C program to find the second largest distinct element in an array of n integers.

## Requirements

- Accept n from the user.
- Accept n integer elements.
- Find the largest and second-largest distinct elements.
- Display the second-largest element.

## Example

Input:
12 45 7 23 45 18

Output:
Second largest element = 23
