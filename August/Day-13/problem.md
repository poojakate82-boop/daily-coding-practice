# Day-13: Find Duplicate Elements in an Array

## Problem Statement

Write a C program to accept `n` integers in an array and find all duplicate elements.

## Input

- Enter the number of elements `n`.
- Enter `n` integer elements.

## Output

- Display all duplicate elements present in the array.

## Example

### Input

7
10 20 30 20 40 10 50

### Output

Duplicate elements are:
10
20

## Constraints

- 1 <= n <= 100
- Array elements are integers.

## Concept Used

- Arrays
- Nested loops
- Comparison operators
- Duplicate detection
