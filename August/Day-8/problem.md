# Day-8: Count Positive and Negative Numbers

## Problem Statement

Write a C program to accept `n` integers in an array and count the number of positive and negative elements.

## Input

- Enter the number of elements `n`.
- Enter `n` integer elements.

## Output

- Display the total number of positive elements.
- Display the total number of negative elements.

## Example

### Input

6
10 -5 20 -8 7 -2

### Output

Positive numbers = 3
Negative numbers = 3

## Constraints

- `1 <= n <= 100`
- Array elements are integers.

## Concept Used

- Arrays
- For loop
- If-else-if
- Comparison operators
