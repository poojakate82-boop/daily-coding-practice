# Day-10: Find the Average of Array Elements

## Problem Statement

Write a C program to accept `n` integers in an array and calculate the average of all elements.

## Input

- Enter the number of elements `n`.
- Enter `n` integer elements.

## Output

- Display the average of all array elements.

## Example

### Input

5
10 20 30 40 50

### Output

Average = 30.00

## Constraints

- `1 <= n <= 100`
- Array elements are integers.

## Concept Used

- Arrays
- For loop
- Sum calculation
- Type casting
- Average formula
