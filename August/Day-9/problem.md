# Day-9: Search an Element in an Array

## Problem Statement

Write a C program to accept `n` integers in an array and search for a given element.

If the element is present, display its position. Otherwise, display "Element not found".

## Input

- Enter the number of elements `n`.
- Enter `n` integer elements.
- Enter the element to search.

## Output

- Display the position of the element if it is found.
- Otherwise, display "Element not found".

## Example

### Input

5
10 20 30 40 50
30

### Output

Element found at position 3

## Constraints

- `1 <= n <= 100`
- Array elements are integers.

## Concept Used

- Arrays
- For loop
- If statement
- Linear search
