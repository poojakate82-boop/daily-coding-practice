# Day-19: Check Whether a String is Palindrome

## Problem Statement

Write a C program to check whether a given string is a palindrome or not.

A palindrome is a string that reads the same forward and backward.

## Input

- Enter a string.

## Output

- Display whether the string is a palindrome or not.

## Example

### Input

madam

### Output

The string is a Palindrome.

## Constraints

- String length <= 100 characters

## Concept Used

- Strings
- Loops
- Conditional Statements
- String Comparison
