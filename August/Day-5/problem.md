# Day-5: Find the Largest Element

## Problem Statement

Write a C program to accept `n` integers in an array and find the largest element in the array.

## Input

- Enter the number of elements `n`.
- Enter `n` integer elements.

## Output

- Display the largest element in the array.

## Example

### Input

5
12 45 7 89 23

### Output

Largest element = 89

## Constraints

- `1 <= n <= 100`
- Array elements are integers.

## Concept Used

- Arrays
- For loop
- If statement
- Array indexing
