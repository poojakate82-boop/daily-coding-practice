# Day-16: Matrix Multiplication

## Problem Statement

Write a C program to multiply two matrices and display the resultant matrix.

## Input

- Enter rows and columns of the first matrix.
- Enter rows and columns of the second matrix.
- Enter elements of both matrices.

## Output

- Display the resultant matrix after multiplication.

## Example

### Input

First Matrix:
1 2
3 4

Second Matrix:
5 6
7 8

### Output

19 22
43 50

## Constraints

- 1 <= rows, columns <= 10
- Matrix elements are integers.

## Concept Used

- 2D Arrays
- Nested Loops
- Matrix Multiplication
- Array Indexing
